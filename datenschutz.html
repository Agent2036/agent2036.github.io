Datenschutzerklärung – rclone-vault

rclone-vault ist ein privates Werkzeug. Es greift nur auf das Google Drive des Betreibers selbst zu.

  • Die App liest und schreibt Dateien im eigenen Google Drive des Betreibers.
  • Die Daten werden nur auf dem eigenen Server des Betreibers gespeichert.
  • Die App gibt keine Daten an Dritte weiter.
  • Die App verkauft keine Daten und nutzt sie nicht für Werbung.
  • Die App erhebt keine Daten von anderen Personen.

Die Nutzung von Google-Daten folgt der Google API Services User Data Policy.

Den Zugriff widerrufst du jederzeit unter myaccount.google.com/permissions.
